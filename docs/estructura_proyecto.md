## SISTEMA DE ORGANIZACION DE TAREAS ACADEMICAS
Actualmente muchos estudiantes tienen dificultades para organizar sus tareas, actividades y fechas de entrega, lo que genera olvidos, estrés y bajo rendimiento académico. Debido a esto, nace la idea de crear StudyTask, una aplicación enfocada en mejorar la organización estudiantil mediante herramientas simples y fáciles de usar.
El proyecto busca brindar una solución práctica que permita a los estudiantes administrar mejor su tiempo y mantener un control adecuado de sus responsabilidades académicas.
## OBJETIVO GENERAL
Desarrollar una aplicación que permita a los estudiantes organizar y administrar sus tareas académicas de forma sencilla, ayudando a mejorar la planificación y el control de sus actividades.
## OBJETIVO ESPECIFICO
Registrar tareas académicas.
Organizar tareas por cursos.
Guardar fechas de entrega.
Visualizar tareas pendientes y completadas.
Mejorar la organización y manejo del tiempo del estudiantes
## CARACTERISTICAS PRINCIPALES
Registro de tareas académicas.
Organización de tareas por materias o cursos.
Control de fechas de entrega.
Visualización de tareas pendientes y completadas.
## FUNCIONAMIENTO DEL SISTEMA
El usuario abre la aplicación.
Registra una nueva tarea.
Ingresa el curso y la fecha de entrega.
Guarda la información.
El sistema muestra las tareas pendientes y completadas.
