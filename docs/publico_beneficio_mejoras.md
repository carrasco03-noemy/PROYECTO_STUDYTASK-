El proyecto está dirigido principalmente a:
Estudiantes de colegio.
Estudiantes de instituto.
Estudiantes universitarios.
También puede ser utilizado por cualquier persona que necesite organizar actividades o responsabilidades académicas.

Beneficios del proyecto
Mejora la organización académica.
Reduce olvidos de tareas.
Facilita el manejo del tiempo.
Ayuda a mejorar el rendimiento estudiantil.
Permite tener toda la información académica organizada en un solo lugar.
Futuras mejoras
En el futuro, StudyTask podría incluir nuevas funciones como:
Recordatorios automáticos.
Calendario académico interactivo.
Notificaciones de tareas próximas.
Inicio de sesión para usuarios.
Aplicación móvil para Android.
