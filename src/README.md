# PROYECTO STUDYTASK
## DESCRIPCION
- Es una applicacion creada para ayudar a los estudiantes a organizar sus tareas,cursos y actividades academicas de manera rapida y sencilla.Esta aplicacion permitira resgistrar tarea guardar fechas de entrega visualizaractividades pendientes,ayudando a mejorar el control y la organizacion del tiempo de estudio.
- Este proyecto es util por que ayuda a evitar retrasos en las entregas ,facilitando una mejor planificacion academica,esta dirigido principalmente a estudiantes de colegio,institutos,universidades que buscan una forma practica y tecnologica de organizar sus responsabilidades diarias.
## CONTEXTO 
- Este proyecto existe por que muchos estudiantes tienen dificultades para organizar sus tareas o trabajos lo que provoca estres y bajo rendimiento academico ademas aunque la tecnologia este presente en la vida diaria ,no todos cuentan con una herramienta simple y practica que los ayude administrar mejor sus actividades escolares.
- la meta principal de este proyecto `STUDYTASK` es la ayuda que brindara a los estudiantes a mejorar su organizacion de sus actividades este proyecto busca facilitar el control de tareas y contribuir a que los estudiantes sean mas responsables ,ordenados y eficientes en sus estudios.
### CARACTERISTICAS
✅ Registro y organizacion de tareas academicas
✅ Guardado de fechas de entrega y actividades importantes
✅ Visualizacion de tareas pendientes y completadas 
✅ Organizacion de actividades por curso o materia
